# Working on this project

Read `README.md` first — it explains what the project is and how to build it.

## Who you're working with

Sanjay is non-technical. Explain things in plain English with real-world
analogies, break work into small steps, and say what you're about to do before
you do it. Don't assume — if a request has more than one reasonable reading,
say so and ask rather than picking silently.

## The one rule that will bite you

**Edit `template.html`. Never edit `beatass.html`.**

`beatass.html` is generated by `python3 build.py`. Any edit made directly to it
is destroyed on the next build. After changing `template.html`, always run the
build before testing or delivering.

## Verify, don't assume

There is a real browser test — `npm test`. Run it after any change to layout,
the doll, or the GIF code. It catches the two failure modes that matter most
here and are invisible in the source:

1. **Scrolling.** The whole point of the current layout is that it fits on one
   screen. The test measures document height against window height at seven
   viewport sizes. A CSS change that looks fine on your screen can silently
   break a 360×640 Android.
2. **The GIF.** The test pulls the generated bytes back out and checks the file
   really starts with `GIF89a`. A broken encoder still produces an `<img>` that
   looks like something is there.

## House style for this codebase

- Plain HTML, CSS, and JavaScript in one file. No framework, no build tooling
  beyond `build.py`. Don't introduce React, Tailwind, or a bundler.
- No emoji used as icons anywhere. Icons are hand-authored inline SVG in the
  `<defs>` block. Emoji were removed deliberately — they were the loudest
  "generated by AI" signal in the design.
- Nothing is a perfect rectangle. Boxes use uneven `border-radius` values so no
  two corners match; that's what makes them read as pen-drawn. Keep that.
- Three inks doing three jobs: ballpoint blue (`--ink`) for text, red pen
  (`--red`) for labels and annotations, highlighter yellow (`--hl`) for
  emphasis. Don't add a fourth accent without a reason.
- Body text is meant to sit **on** the printed rules. `--rule-h` is 30px and the
  page background is offset by 4px to line the baselines up. Changing body
  font-size or line-height breaks that alignment — re-measure if you touch it.

## Things that were decided on purpose

Don't "fix" these without asking:

- The GIF is 260×260 and ~600 KB. Bigger was 2.1 MB and too heavy for email.
- Recording auto-starts on first touch and runs 4.8 seconds. There is no
  separate record button by design.
- Landscape phones (under 470px tall) are allowed to scroll.
- The warning about blind anonymous mail, and the "Report this" / "Block my
  address" links in the mock email, are not filler. They're the product's
  defence against being treated as an abuse pipe. Keep them.
- Instagram DM support was removed because Instagram's API cannot cold-DM a
  handle. Don't add it back on the assumption it's possible.
